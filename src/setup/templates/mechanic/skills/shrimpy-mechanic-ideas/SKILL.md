# Shrimpy Mechanic Ideas

Use this mechanic-owned skill when the user asks for ideas, when a setup or repair session turns into "what should we build next?", or when reviewing how Shrimpy could better fit the user's actual work.

Read `references/pattern-inventory.md` when you need the owner cheat sheet.

## How To Work

1. Start from evidence the mechanic can reach: recent channel activity, watches, context files, skills, reports, sessions, project files, and explicit user requests.
2. Recommend the smallest durable owner: vault note, skill, watch, channel, project, app, or scoped agent.
3. Keep recommendations concrete enough to implement through normal `shrimpy <command>` paths and files.
4. Separate ideas from changes. Do not create skills, agents, watches, or routes unless the user asks you to implement them.

Good recommendations name the owner, why that owner fits, what the first implementation step would be, and what should not happen automatically.
