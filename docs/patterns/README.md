# Shrimpy Patterns

Short shared workflow patterns. These docs describe reusable Shrimpy shapes so skills can point here instead of burying common knowledge in one agent's instructions.

Read the relevant pattern first. If you need command detail or exact current behavior, follow that pattern's reference-doc breadcrumbs.

- [watches.md](watches.md) — recurring work, reminders, checks, and monitors.
- [channels.md](channels.md) — routing work and logs through channels.
- [vault.md](vault.md) — durable files, captures, research packets, and artifacts.
- [memory.md](memory.md) — searching existing workspace knowledge before acting.
- [workers.md](workers.md) — clear worker handoffs and result checks.
