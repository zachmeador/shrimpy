# 🦐 CTX-007: Session-Status Turn Context Items

Status: done
Priority: P1
Area: Context

## Why
Scheduled turns need awareness of active or stale work without loading full transcripts. A compact session-status item can point agents toward the right channels and recent activity.

## Build
- Add active session summaries to scheduled turn context.
- Include latest activity, channel, and stale hints.
- Keep output concise and inspectable through existing or new CLI surfaces.

## Boundaries
- Do not replay raw transcripts.
- Do not create a second scheduler or heartbeat control plane.

## Notes
- Implemented with recency-based active/stale classification from session file mtimes. It does not probe live processes or infer blocked/running outcomes.

## Done
- Scheduled turn-context items show useful session-status pointers.
- Ordinary chat turn-context items remain compact.
- Tests cover no-active-session, active-session, and stale-session cases.
