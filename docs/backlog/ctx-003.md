# 🦐 CTX-003: High-Value Turn Briefing Facts

Status: todo
Priority: P1
Area: Context

## Why
Turn briefings should tell the agent what matters about the current routed turn without replaying raw state. Surface/user metadata, addressed-agent state, scheduler origin, and attention decisions are high-value facts that help the agent behave correctly.

## Build
- Add concise briefing facts for surface and user metadata.
- Include peer-card pointers and addressed-agent state when available.
- Include scheduler origin and wake reason for scheduled turns.
- Include attention decision metadata.

## Boundaries
- Keep facts pointer-heavy and compact.
- Do not duplicate channel logs, full peer memory, or raw session transcripts in the briefing.

## Notes
- Likely files: `src/context/turn/service.ts`, `src/context/env.ts`, `src/surfaces/shared/thread-state-store.ts`, and channel message origin types.
- Preserve stable prompt resources as long-lived context; live state belongs in the turn briefing.

## Done

- Facts stay bounded under existing briefing limits.
- Tests cover Telegram, scheduler, and normal channel-origin cases.
